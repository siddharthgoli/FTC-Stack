FTC Stack is a free, open source educational project created by **FTC Team #14481 Don't Blink**.

Our mission is to make high quality FTC programming education accessible to every team. We believe that students shouldn't have to reverse engineer successful codebases or rely on scattered tutorials to learn modern software development practices.

This curriculum combines lessons from competitive robotics with established software engineering principles to teach students how to write code that is clean, maintainable, and scalable.

## Why we created this

When learning FTC programming, it's easy to find examples that explain _what_ to do, but much harder to find resources that explain _why_ successful teams structure their code the way they do.

FTC Stack aims to bridge that gap by providing a structured learning path that starts with the fundamentals and gradually introduces more advanced concepts.
