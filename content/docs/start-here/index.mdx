## Set up your robot

1. [Install Android Studio](/docs/start-here/installing-android-studio).
2. [Set up FTC Robot Controller](/docs/start-here/ftcrobotcontroller).
3. [Find your way around the project](/docs/start-here/project-structure).
4. [Configure your robot hardware](/docs/start-here/robot-config).
5. [Learn how to create and run an OpMode](/docs/start-here/opmodes).

If Java is new to you, work through [Java Fundamentals](/docs/start-here/java-fundamentals) before writing your first OpMode.
